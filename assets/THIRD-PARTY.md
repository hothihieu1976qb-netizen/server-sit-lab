# 第三方资源

## Lucide 图标

- 上游项目：https://github.com/lucide-icons/lucide
- 源文件：https://github.com/lucide-icons/lucide/tree/main/icons
- 获取日期：2026-11-17，来自当日 `main` 分支。
- 许可：ISC；继承自 Feather 的部分图标同时遵循 MIT，完整原文位于 `lucide/LICENSE`。
- 使用方式：保留选用 SVG 源文件，将内部路径汇集到 `lucide/icons.js`；统一尺寸、描边后以内联 SVG 渲染。
- 图标已经随项目保存，页面运行时不会请求 GitHub 或 CDN。

服务器立体示意、课程配图、视觉样式和交互均由本项目代码绘制，没有使用第三方截图或网页模板。
